# tpf-lider

Aplicação Leader do Trabalho Prático Final de Sistemas Distribuídos.

## Configuração

Criar um ficheiro `.env` na raiz do projeto com:

DISCORD_TOKEN=<token_do_bot>

O ficheiro `.env` não deve ser adicionado ao repositório.

## Execução

Executar a classe:

tpf.LeaderBot

O bot liga-se ao servidor Discord e regista os comandos disponíveis no servidor de teste.
